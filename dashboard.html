Producing a customer card

The flow you follow for every customer.

  1. Create card — fill in the customer's name and links.
  2. Design — open the card designer, pick theme and accent.
  3. Print — print front & back at exact CR80 size.
  4. Write NFC — copy the customer's NFC URL into any NFC writing app and write it to the chip.
  5. Test & issue — tap the card with a phone, then set status to Issued.

Writing steps

Use any NFC writing app (Android: NFC Tools, NFC Writer…).

  1. Copy the NFC URL above.
  2. Open an NFC writing app on your phone.
  3. Select Write.
  4. Add a URL / URI record.
  5. Paste the TapX URL.
  6. Hold the NFC card near the phone.
  7. Write the URL to the chip.
  8. Test — tapping must open the profile directly.
Your NFC chip must be physically installed in your card and programmed with this URL. The TapX website does not contain or physically install the NFC chip. TapX does not physically write NFC chips — use an NFC-enabled phone and an NFC writing app to program the card.
Do not write sensitive personal information directly to the NFC chip. Store only your TapX URL — NFC data can be read by anyone who taps the card.
